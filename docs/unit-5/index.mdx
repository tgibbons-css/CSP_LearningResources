### Explore a dataset

Pick a topic that interests you. TidyTuesday is organized by the Data Science Learning Community; its dataset pages include background and information about the data. Open a year below to browse the examples selected in the original resource list.

For a GitHub dataset, open its README, review the data dictionary, and locate a CSV file to download and import into Sheets. You can use the data without running the R or Python examples shown on those pages.
