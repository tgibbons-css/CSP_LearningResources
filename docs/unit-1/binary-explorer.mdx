## Reading: four bits, sixteen possibilities

A bit has two possible values: **0** or **1**. In this four-bit representation, the place values from left to right are **8, 4, 2, and 1**. Add the place values of the bits set to 1 to find the decimal value. For example, binary **0101** represents **4 + 1 = 5**.

## Interactive activity

Try representing **5**, then **10**, then **15**. Use Tab to reach a bit and Space or Enter to toggle it. On a touchscreen, tap the bit.
