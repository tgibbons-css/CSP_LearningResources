## From a spreadsheet to a server cluster

A small table can fit on a laptop. A service receiving many simultaneous requests, storing many copies of media, or training a large model may need much more compute, storage, and network capacity. Distributed systems spread work across machines, but those machines still need racks, cables, electricity, maintenance, and cooling. [Cloudflare’s cloud overview](https://www.cloudflare.com/learning/cloud/what-is-the-cloud/) connects remote services to the physical servers that deliver them.

Scale creates pressure; it does not make one enormous building the only possible design. Workload reduction, efficient software, location choices, and sharing or distributing resources also matter.

## The 5 V’s of Big Data

Use **Volume** (amount), **Velocity** (arrival and processing rate), **Variety** (formats), **Veracity** (trustworthiness), and **Value** (useful outcomes) to describe a workload. Which V increases resource needs? Which might help us decide whether the work is worth doing?

## Supporting context: Data formats

Compare a table with consistent columns, a JSON record with keys and nested values, and an image or audio file without that tabular schema. “Unstructured” does not mean meaningless. JSON has structure even when records vary. AI workloads can combine structured records, JSON, text, and media; **format alone does not determine size**.

- [AWS: Structured Data vs. Unstructured Data](https://aws.amazon.com/compare/the-difference-between-structured-data-and-unstructured-data/)
- [MDN: Working with JSON](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/JSON)
- [YouTube: IBM Technology - Structured vs Unstructured Data Explained](https://www.youtube.com/watch?v=eK3I6oI_4Is)

## Supporting context: Distributed computing and cloud infrastructure

Parallel computing performs work concurrently. Distributed computing coordinates machines connected by a network. Cluster storage spreads data across machines and may replicate it for resilience. Adding machines can increase capacity, but communication, coordination, and network bottlenecks can limit the benefit. Use the sources below to connect these ideas to physical infrastructure.

- [AWS: What Is Cloud Computing?](https://aws.amazon.com/what-is-cloud-computing/)
- [AWS: What Is Distributed Computing?](https://aws.amazon.com/what-is/distributed-computing/)
- [IBM Technology - What are distributed systems?](https://www.ibm.com/think/topics/distributed-systems)
- [Cloudflare: What Is the Cloud?](https://www.cloudflare.com/learning/cloud/what-is-the-cloud/)
